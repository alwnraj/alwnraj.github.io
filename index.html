Crazyflie Figure-8 Flight with OptiTrack

I built a motion-capture-guided controller that maps OptiTrack pose data into the Crazyflie’s local frame, streams external-position estimates to the drone, and autonomously tracks a cage-aware figure-8 path in X/Y. Altitude is defined in code and maintained throughout flight through continuous motion-capture feedback.
